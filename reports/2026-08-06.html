Jargon Decoder — terms used this run, one line each
Optical transceiver — pluggable module converting electrical signals to light & back for datacenter links; just a "PHY," it never sees decrypted data (why IA calls the security ban-rationale bogus).
Active / six-axis alignment — sub-micron positioning of laser/fiber/lens inside a module; the hard yield step Chinese makers (Innolight, Eoptolink, Accelink) dominate with custom tools.
EML vs SiPho module — two transceiver designs; SiPho uses ~50% less indium-phosphide but more alignment work. Pivoting between them is easy — alignment capacity is the real constraint.
InP (indium phosphide) — III-V substrate lasers are grown on; ~80% of output already feeds AI optics with no consumer fallback → "shortage worse than DRAM." AXTI = pure-play.
SiPho PIC — silicon-photonic chip that routes the light; Tower's Openlight PDK integrates InP lasers onto it, so LITE/COHR/AAOI all route their PICs through Tower.
CMIS — the standard host↔transceiver command register map, with a signed-key firmware system — IA's argument for why a module can't covertly run malware.
HBF (High Bandwidth Flash) — new NAND-based memory tier between DRAM and SSD for AI inference; SK Hynix + SanDisk published the first OCP spec (Aug 3), Google/Tenstorrent backing.
CPO / ELSFP — co-packaged optics moves the laser out of the switch package to cut power; needs high-power narrow-linewidth external lasers — LITE's niche.
Helios / MI455X — AMD's 2027 rack-scale GPU system; first units ship end of Q3 2026 — the make-or-break of its CUDA-moat challenge.
CXMT / SiCarrier — China's DRAM champion (LPDDR6 at 12.8 Gbps) and a stealth domestic DUV-litho maker; together, evidence China's memory/equipment self-sufficiency is going operational.
Retimer — chip that catches a dying high-speed PCIe signal mid-board and relaunches it clean; Astera's franchise product, in every AI server (Semi Doped pod).
Kimi Delta Attention — Moonshot's linear-attention layer in Kimi K3 that compresses long context into a fixed-size memory state — cheaper serving vs full softmax attention.
