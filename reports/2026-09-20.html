Jargon decoder

Engram — DeepSeek architecture that stores recurring token patterns as looked-up vectors, so the model reconstructs less through attention. Fewer HBM GB needed per model at equal quality.
Parameter offloading — parking rarely-used model tables in cheap host DRAM (or SSD) and prefetching them, freeing scarce HBM for weights + KV cache.
CUDA moat — Nvidia's software lead (day-0 vLLM/SGLang support, kernel tuning). SemiAnalysis: AMD MI355X still 2–4× worse tokens/$ than B200 even after TCO adjustment.
4-hi HBM / de-spec — stacking 4 memory dies instead of 8/12. For inference, bandwidth > capacity, so 4-hi gives the best $/bandwidth — the running memory theme.
Behind-the-meter (BTM) — on-site power (fuel cells, gensets) that skips the grid queue. Grid interconnect is the bottleneck, so BTM is now core datacenter infra.
800V DC architecture — distributing high-voltage DC through the rack instead of AC; cuts conversion losses and copper for dense GPU trays. Bloom's new pitch.
NPO (near-packaged optics) — optics beside the switch ASIC (one step short of co-packaged). Huawei's Hi-ONE claims 7.2 Tbit/s/engine, first mass-production NPO with built-in laser.
UnifiedBus — Huawei fabric claiming to bind up to 1M processors into one logical computer via unified memory addressing; the scale-up backbone of its Tau-scaling pitch.
CXL — memory-pooling interconnect. An OpenAI panelist at AI Infra Summit: "I cannot find a use case for CXL" in live model operation — a recurring skeptic datapoint.
CCL / MLCC — copper-clad laminate (the base of every server PCB) and multi-layer ceramic capacitors (power smoothing). Both are AI-server bottlenecks; CCL lead times ≈ 1 year.
Hybrid bonding — copper-to-copper die stacking (BE Semiconductor's tool niche). The HBM de-spec to 8-/4-hi removes the need for it, pressuring the trade.
InP optical engine PIC — indium-phosphide photonic chip with the laser integrated and field-serviceable; Tower + NewPhotonics now shipping in volume for AI scale-up links.
