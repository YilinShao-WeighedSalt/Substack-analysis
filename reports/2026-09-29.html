Jargon decoder

PowerVia / BSPDNIntel's backside power delivery — moves the power network behind the transistors, freeing frontside routing; Panther Lake is the first commercial implementation.
RibbonFET / GAAGate-all-around transistor: the gate wraps the channel on all four sides (vs FinFET's three) for tighter leakage control; Intel's first GAA arrives on 18A.
18AIntel's leading-edge node and comeback proof point — first to ship BSPD+GAA, but its logic density only matches TSMC's older N3E.
Foveros-SIntel's 2.5D packaging — active compute/GPU/I-O tiles bonded onto a passive silicon base, so each function can use a different, cheaper node.
N2 / 2nmTSMC's next node; '120k wafers/month by end-2026' would be one of its fastest leading-edge ramps ever.
FC-BGA substrateThe high-layer-count package linking an AI accelerator die to the board — a supply chokepoint; Samsung Electro-Mechanics is adding $4.4B of capacity.
Sparse attention (DSA)Attention that reads only the top-k most relevant tokens — cuts compute/bandwidth but NOT overall HBM capacity, since top-k still needs the full context resident.
KV-cache offloadMoving cached attention state from HBM out to host DRAM (e.g. HiSparse) to serve longer contexts and higher concurrency.
HBM5Next HBM generation; SK Hynix validated its HBM5 architecture on TSMC's CoWoS packaging this week.
TileRT / ATOMAMD's low-latency inference engine (single persistent decode kernel) and serving stack on MI355X — closing on Nvidia but with weak time-to-first-token.
High-NA EUVHigher-numerical-aperture extreme-ultraviolet litho for the next nodes; ASML's 2027 EUV output is fully sold out.
SolidigmSK Hynix's NAND/SSD unit — weighed for a ~$150B US IPO, whose dilutive optics knocked the parent's shares.
