# Daily Update — August 27th, 2026

News-dense daily. Headline: **Nvidia's FQ2 print anchors the whole compute stack to a longer build cycle.**

## Summary

- **Nvidia FQ2 / guidance.** Guided ~**70% revenue growth for FY2027** and told investors the AI-spend surge extends into **2028** — "no credible off-ramp" for hyperscalers/sovereigns. Mizuho's Rakesh notes the Street is now using Nvidia's own capex as a conviction proxy. Austin: **Rubin is probably the fastest revenue ramp in history**; full-stack Vera Rubin ~**$40B/GW** per Jensen; CPUs a **$20B/yr** business (host + standalone Vera racks); enterprise GenAI + robotics/AV still growing. *Also:* Nvidia allegedly agreed to **buy Hugging Face for $12.9B** (The Information).
- **AWS + Nvidia — 2M more GPUs.** AWS to deploy **2M additional Nvidia GPUs in 2027–28** (Blackwell Ultra / Rubin / Rubin Ultra + Vera CPU), on top of 1M+ already planned from 2026; 100k into secure US-gov infra. **Anthropic locks a 6-yr $45B compute deal with Nscale.** Shifts GPU acquisition from spot to multi-year commitments → higher baseline utilization. Austin: the zero-sum GPU-vs-XPU frame is wrong — AWS runs 1M+ Trainium2, Trainium3 shipping, and *still* bought millions more Nvidia GPUs.
- **NVHBM.** Nvidia expands **NVLink Fusion** with **NVHBM** — moves its custom memory controller **into the HBM base die** (vs on the XPU): claims **+30% BW, −15% HBM power, +25% free XPU compute-die area** vs standard HBM4E. Nvidia defines one standard implementation validated/sold by multiple memory vendors; **Amazon's Annapurna is first partner** (Trainium4). Austin: the custom HBM4 base die is another content-sell opportunity for Nvidia.
- **Kioxia + SanDisk $31B NAND.** Joint **>$31B** investment in Japan, centered on a new **Fab3 at Kioxia's Kitakami plant** — an explicit response to **YMTC** (targeting top-3 NAND by 2027; faces US-export equipment constraints).
- **Synopsys.** Q3 rev **$2.477B**, GAAP EPS **$2.84** — beats, **raises FY2026 guide**. Backdrop: accelerating hyperscaler custom-ASIC + chiplet adoption = intensive front-end EDA work before tapeout.
