- **SK Hynix in talks with Intel** to manufacture memory inside Intel's long-planned Ohio fab — first time a Korean memory giant would produce DRAM offshore at scale (US gov't pushing via tariff threat; SK Hynix "exploring options," no plans confirmed). Reframes IFS foundry revenue + supply-chain geography.
- **AWS writes off Bahrain + one UAE availability zone** as beyond recovery after Iranian Gulf strikes (6 months on) — data unrecoverable; sits inside a $220B capex plan; UAE weighing underground DCs.
- **Samsung routes all new DDR5 module output to OSATs**, redirecting internal capacity to HBM and pressing partners to build out; begins **Tesla AI5** prototype production at its foundry (narrows gap to TSMC).
- **Astera Labs** launches **Leo 2** (CXL 3.2 / PCIe Gen6) memory controllers + a new **Leo X** rack-scale fabric-attached memory controller.
- Also: Altera confidential US IPO (FPGA pure-play); IBM-Anderon $1B CHIPS award for a quantum wafer foundry (first CHIPS quantum grant); TeRAM $37M 3D-SRAM stealth; Hanmi first tool order at TSMC Terafab; Microsoft stands up an **AION 2** custom-chip team; Schneider 2.5MW prefab power modules; Huawei 3D DC architecture (100k Ascend/supernode); NY proposes $1M/MW community-benefit rule.
